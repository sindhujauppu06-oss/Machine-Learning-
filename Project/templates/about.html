About Insurance Claim Fraud Detection

AI & DS Mini Project | KLH University

Project Objective

Insurance Claim Fraud Detection is a Machine Learning web application that predicts whether a vehicle insurance claim is genuine or fraudulent using Bayesian Optimized XGBoost.

Dataset

fraud_oracle.csv containing vehicle insurance claim records.

Machine Learning Algorithm

  • Basic XGBoost
  • Grid Search XGBoost
  • Bayesian Optimized XGBoost (Final Model)

Technologies Used

Python Flask HTML5 CSS3 Pandas XGBoost Joblib

Final Model Accuracy

95.43% Accuracy using Bayesian Hyperparameter Optimization
